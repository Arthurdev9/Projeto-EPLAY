🛒 Projeto E-PLAY

Aplicação web desenvolvida com React, TypeScript e Styled Components, utilizando Redux para gerenciamento de estado global e Redux Toolkit Query para consumo de APIs. O projeto também conta com Formik para validação de formulários e layout totalmente responsivo.

🚀 Tecnologias utilizadas

React

TypeScript

Styled Components

Redux

Redux Toolkit Query

Formik

Yup (validação de formulários)

Create React App

📱 Funcionalidades

Listagem de produtos via API

Gerenciamento de estado global com Redux

Consumo de dados com Redux Toolkit Query

Formulários com validação usando Formik

Layout totalmente responsivo

Estilização com Styled Components

🎯 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar:

Arquitetura com React e TypeScript

Gerenciamento de estado com Redux

Consumo de APIs com RTK Query

Boas práticas de organização de código

Validação de formulários com Formik

Criação de layouts responsivos
